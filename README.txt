VOIDFORM — MULTI-PAGE WEBSITE
================================

Zawartość:
- index.html   — Home
- about.html   — O nas / Manifest
- offer.html   — Oferta
- gallery.html — Galeria / Flash Lab
- contact.html — Kontakt
- style.css    — wspólny styl wszystkich podstron
- script.js    — menu mobilne, filtrowanie galerii, formularz kontaktowy

JAK URUCHOMIĆ
1. Rozpakuj ZIP.
2. Otwórz index.html w przeglądarce albo wrzuć wszystkie pliki do jednego katalogu na hostingu.
3. Podstrony korzystają ze wspólnego style.css i script.js — zachowaj te pliki w tym samym katalogu.

JAK WDROŻYĆ NA GITHUB PAGES
1. Pobierz/otwórz repozytorium VoidStudio.
2. Zrób kopię zapasową obecnych plików.
3. Wgraj pliki z paczki do katalogu głównego repozytorium.
4. Zatwierdź zmiany (Commit changes). GitHub Pages opublikuje aktualizację.

WAŻNE
- To gotowy, samodzielny pakiet wielostronicowy. Nie modyfikuje automatycznie zdalnego repozytorium.
- Formularz kontaktowy przygotowuje wiadomość w domyślnej aplikacji pocztowej; nie zapisuje danych ani nie wysyła ich przez serwer.
- Adres hello@voidform.studio i profil @VOIDFORM.INK zostały zachowane jako elementy projektu widoczne na istniejącej stronie — przed publikacją sprawdź, czy są aktualne.
- Grafiki w kartach są tworzone w CSS jako abstrakcyjne wizualizacje, więc nie wymagają dodatkowych plików obrazów.
- Fonty z Google Fonts wymagają połączenia z internetem; w razie braku połączenia zastosowane zostaną fonty zapasowe.
